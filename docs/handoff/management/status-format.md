# Manager Status Format

Use concise evidence-oriented updates.

## Current milestone

State the milestone and actual integrated capability.

## Newly proven

List only observed behavior with evidence links.

## In flight

| Task | Owner | State | Dependency or blocker |
|---|---|---|---|

## Highest risk

One to three concrete risks and mitigation.

## Decisions made

Only meaningful decisions, with ADR links.

## Next integration wave

State the next outcomes, not activity.

Avoid percent-complete estimates without a measurable basis.
